# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**. The game allows two players to play Tic Tac Toe in the browser with a clean and responsive user interface.

## 🚀 Live Demo

[Play Tic Tac Toe](https://github.com/Divyanshmishraa/tic-tak-toe-game.git)

## 📌 Features

- 🎮 Two-player gameplay
- ❌ Player X and ⭕ Player O
- 🏆 Automatically detects the winner
- 🤝 Detects a draw when all cells are filled
- 🔄 New Game / Restart functionality
- ⚡ Interactive user interface
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the game
- **CSS3** – Provides styling and layout
- **JavaScript** – Handles game logic and user interactions
